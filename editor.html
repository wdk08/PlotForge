    Keyboard guide

    Drag a toolbar tool
    Drop it on the canvas to insert it. Use Enter or Space on a focused tool to insert at the center.
    Drag empty space
    Draw a selection box. Hold Shift to add to the selection or Shift-click to toggle individual cards.
    Scroll or Space + drag
    Pan in either direction.
    Pinch or ⌘ / Ctrl + + / −
    Zoom the canvas. Use ⌘ / Ctrl + 0 to reset to 100%.
    Double-click
    Edit text or open a nested canvas.
    ⌘ / Ctrl + Z
    Undo. Add Shift to redo.
    ⌘ / Ctrl + C, X, V
    Copy, cut, or paste. Pasting plain text creates a text box.
    ⌘ / Ctrl + A
    Select all elements on this canvas.
    ⌘ / Ctrl + D
    Duplicate the selection.
    ⌘ / Ctrl + S
    Save this project locally now.
    Delete / Backspace
    Delete the selection.
    Escape
    Finish editing text or clear the current selection or tool.
